precip = raw_data.astype(np.float32)

## ⏱️ 时间特性

### 文件命名

```
RAD_NL25_RAP_5min_YYYYMMDDHHMM.h5
```

**示例**:
- `RAD_NL25_RAP_5min_201008260530.h5`
- `RAD_NL25_RAP_5min_201008260555.h5`

**解析**:
- `RAD`: Radar
- `NL25`: Netherlands 2.5km (可能的历史分辨率)
- `RAP`: Rapid / Precipitation
- `5min`: 5分钟时间间隔
- `YYYYMMDDHHMM`: 年月日时分

### 时间分辨率

| 属性 | 值 |
|------|-----|
| **时间间隔** | 5 分钟 |
| **数据日期** | 2010-08-26 |
| **可用时间** | 01:30 - 05:55 UTC |
| **文件总数** | 92 个 |

### 时间序列长度

**优势**: 92 个文件 = **460 分钟** (7.67 小时) 的连续数据

**对比**:
- KNMI: 92 个文件 (7.67小时)
- DWD: 7 个文件 (35分钟)

**意义**: KNMI 数据集支持更长时间序列的分析

## 🌍 气候背景

### 荷兰气候特征

| 特征 | 描述 |
|------|------|
| **气候类型** | 海洋性气候 (Cfb) |
| **降水特征** | 频繁、均匀、强度适中 |
| **地理特征** | 低地、沿海、平原 |
| **季节性** | 全年降水，无明显干季 |

### 对预报的影响

1. **降水频繁**
   - 更多样本可用
   - 统计更稳定
   - 预报性能更好

2. **系统移动**
   - 西风带主导
   - 系统移动规律
   - 运动估计准确

3. **地形影响**
   - 地形平坦
   - 地形降水少
   - 分布相对均匀

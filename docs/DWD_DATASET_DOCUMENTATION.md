| **X比例尺** | 1000 米/像素 |
| **Y比例尺** | 1000 米/像素 |

### 数据编码

| 属性 | 值 | 说明 |
|------|-----|------|
| **数据类型** | uint16 | 无符号16位整数 |
| **物理量** | RATE | 降水率 |
| **单位** | mm/h | 毫米/小时 |
| **增益 (gain)** | 0.01 | 乘法因子 |
| **偏移 (offset)** | 0.0 | 加法偏移 |
| **无数据值** | 65535 | nodata 标记 |
| **无探测值** | 0 | undetect 标记 |

### 物理值转换

```python
# 从原始数据到物理值
physical_value = raw_value * gain + offset
physical_value = raw_value * 0.01 + 0.0

# 示例:
# raw_value = 500  →  physical_value = 5.0 mm/h
# raw_value = 5000 →  physical_value = 50.0 mm/h
# raw_value = 65535 → nodata (缺失值)
# raw_value = 0 → undetect (无降水探测)
```

    │   ├── startdate: "20250604"

        ├── what            # 数据属性

## 🔧 数据质量考虑

### 质量标记

| 标记类型 | 值 | 说明 |
|---------|-----|------|
| **nodata** | 65535 | 缺失数据 (地形阻挡、传感器故障) |
| **undetect** | 0 | 无降水探测 (低于检测阈值) |

### 常见问题

1. **地物杂波**
   - 山区可能出现固定回波
   - 需要地物杂波抑制

2. **异常传播**
   - 温度逆层可能导致异常回波
   - 需要质量控制

3. **衰减**
   - 强降水可能衰减雷达波束
   - 远端降水强度可能被低估

## 📖 使用建议

### 短临预报配置

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **输入帧数** | 4-6 帧 | 用于运动估计 (20-30分钟历史) |
| **预报时效** | 5-120 分钟 | 0-2小时短临预报 |
| **时间步长** | 5 分钟 | 匹配数据时间分辨率 |
| **集合成员数** | 20-50 | 平衡准确性和计算效率 |

### 预报性能参考

基于实际测试 (DWD 2025-06-04 数据):

| 时效 | CSI (0.1mm) | CSI (5.0mm) |
|------|-------------|-------------|
| 5 min | 0.997 | 0.964 |
| 15 min | 0.949 | 0.807 |
| 30 min | 0.847 | 0.450 |
| 60 min | 0.591 | 0.041 |
| 120 min | 0.000 | 0.000 |

**观察**:
- 低阈值 (0.1-1.0 mm/h) 在 60 分钟内预报良好
- 高阈值 (≥3.5 mm/h) 在 30 分钟内表现优秀
- 60 分钟后所有阈值性能显著下降

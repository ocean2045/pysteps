## 🎓 技术洞察

### 数学模型

**CSI 衰减模型**:
```
CSI(threshold, time) = CSI₀ × exp(-α × threshold) × exp(-β × time)

其中:
- CSI₀: 基础性能 (~0.99)
- α: 阈值衰减系数 (~0.15)
- β: 时间衰减系数 (0.01-0.04)
```

**经验公式** (15分钟时效):
```
CSI(t) = 0.95 × exp(-0.15 × t)

验证:
t=0.1 → CSI≈0.94 ✓
t=1.0 → CSI≈0.82 ✓
t=5.0 → CSI≈0.42 ✓
```

### 性能关系

1. **阈值 vs 性能**
   - CSI 随阈值升高而降低
   - 衰减率: 5.0mm/h 比 0.1mm/h 低 **38%**

2. **时效 vs 性能**
   - CSI 随时间呈指数衰减
   - 高阈值衰减速度是低阈值的 **4倍**

3. **转折点**
   - **30 分钟**: 关键转折点
   - **60 分钟**: 性能急剧下降
   - **90 分钟**: 基本失效

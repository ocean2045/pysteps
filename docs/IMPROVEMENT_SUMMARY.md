## 🎓 技术原理

### 为什么当前方法在30分钟后失效？

1. **运动累积误差**
   - 每步5%误差 → 12步后 = 1 - (0.95)^12 = 46%误差

2. **系统演化不可预测**
   - 对流生消
   - 降水增强/减弱
   - 系统合并/分裂

3. **边界效应**
   - 平移导致数据流失
   - 边界不确定性

### 改进方案如何解决？

| 问题 | 解决方案 | 原理 |
|------|----------|------|
| 运动误差 | 增加历史帧 | 更多样本 → 更稳定估计 |
| 系统演化 | NWP融合 | NWP能预测生消 |
| 边界效应 | 气候学补充 | 统计规律填充 |
| 快速衰减 | 时效分段 | 不同时段不同策略 |
